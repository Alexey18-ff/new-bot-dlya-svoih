# Telegram-бот кафе — обновлённая версия

## Что реализовано
- Выбор места доставки на интерактивной карте OpenStreetMap (нажатие по карте, перетаскиваемая метка, геолокация).
- Тип объекта: квартира или коммерческое помещение; номер, подъезд, этаж, код домофона.
- Дополнительные данные и координаты сохраняются в SQLite и отображаются в заказе администратору.
- Ручное добавление и редактирование блюд; импорт меню через вставку/редактирование текста. Распознавания фотографий меню нет.
- Миграция существующей SQLite-базы добавляет новые поля без удаления старых заказов.

## Установка
1. Установите Python 3.10+. Tesseract OCR не требуется.
2. Распакуйте проект, создайте виртуальное окружение и установите пакеты:
   `python -m venv .venv`
   `source .venv/bin/activate` (Windows: `.venv\Scripts\activate`)
   `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL`.
4. Запустите: `python main.py`.
5. Для Telegram Mini App укажите публичный HTTPS-домен в `WEBAPP_URL`.

## Важно
- Карта работает и на хостинге/VPS: она отображается в браузере и загружает тайлы OpenStreetMap через интернет. Leaflet загружается с unpkg CDN.
- Геолокация браузера требует HTTPS и согласия пользователя.
- Для работы карты нужен интернет у пользователя.
- Не удаляйте существующий `cafe.db`: при первом запуске обновлённая программа сама добавит недостающие поля.
